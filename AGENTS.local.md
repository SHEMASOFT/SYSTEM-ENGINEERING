# AGENTS

Generated by `se adapter deepseek` from the canonical contracts. Generated output only; regenerate instead of editing.

DSH reads project instructions from ``AGENTS.md``/``CLAUDE.md`` plus their
``.local.md`` overlays, skills from ``<projectRoot>/.dsh/skills``, and agent
presets only from Cordis patch lists — never a scanned preset directory. So
the roles are rendered as a patch overlay the operator applies with
``--patch``, and the instruction file uses the overlay name so it does not
collide with the ``AGENTS.md`` the Codex adapter writes.

## Roles

- **analyst** — Analyze discovery output and formalize requirements, assumptions, constraints and risks. (model: `openai/gpt-4o`)
- **architect** — Define the architecture and design that satisfies the requirements. (model: `openai/gpt-4o`)
- **devops** — Prepare deployment, operations and rollback for authorized environments. (model: `openai/gpt-4o`)
- **documentation** — Produce and maintain clear, non-duplicated documentation and release notes. (model: `openai/gpt-4o`)
- **explorer** — Discover context, constraints, unknowns and existing state before planning. (model: `openai/gpt-4o`)
- **implementer** — Implement authorized tasks and produce verifiable artifacts. (model: `openai/gpt-4o`)
- **planner** — Decompose requirements into a traceable, unblocked plan of tasks. (model: `openai/gpt-4o`)
- **reviewer** — Independently review artifacts, evidence and process for correctness and quality. (model: `openai/gpt-4o`)
- **security** — Identify security risks and produce security evidence across the lifecycle. (model: `openai/gpt-4o`)
- **shema-ai-coordinador** — SHEMA-AI Coordinador: Orchestrate the lifecycle, route work to agents, enforce gates and traceability, and resolve the work mode for each change from the project profile. (model: `openai/gpt-4o`)
- **tester** — Verify that implementation satisfies requirements and collect evidence. (model: `openai/gpt-4o`)
- **visual** — Produce visual, media and design deliverables and their evidence. (model: `openai/gpt-4o`)

## Commands

- **archive** — Create a verified archive bundle of the project.
- **auto** — Deterministic decision engine: consumes health aggregation and emits a machine-readable next-action decision (se.auto/1).
- **capabilities** — Capability governance: registry, policy check and resolution.
- **context** — Reconstruct the minimum relevant context (AUTO-02).
- **doctor** — Validate the Master System installation and environment.
- **execute** — Execute tasks in topological order with authorization, evidence, fail-closed.
- **explore** — Scan the project and produce a discovery report.
- **gate** — Evaluate a single gate against a project.
- **handoff** — Create or load a HANDOFF.json artifact for project continuity.
- **health** — Aggregate health status from existing checks (doctor, validate, capabilities, review).
- **implement** — Report the next actionable tasks.
- **init** — Create or repair a managed project workspace.
- **intent** — Normalize an explicit structured intent into a READ-ONLY se.intent/1 envelope.
- **new** — Create a record from its template.
- **observe** — Observe execution state: IN_PROGRESS tasks, evidence, artifacts, receipts (READ-ONLY).
- **orchestrate** — Manage deterministic multi-agent workflows (DAG + gates): create, execute, list.
- **plan** — Check requirement coverage and scaffold tasks; with --json derive an ordered READ-ONLY plan envelope (se.plan/1).
- **release** — Create and optionally approve a release artifact.
- **restore** — Restore a project from an archive bundle.
- **review** — Static review of schema, references and coverage.
- **shema-ai** — SHEMA-AI Unified Interface: Model config, Install, Sync, Uninstall, Doctor.
- **trace** — Trace the dependency graph of a project record (read-only).
- **transition** — Advance the project lifecycle through its gates.
- **update** — Apply a controlled, audited mutation to a record.
- **upgrade** — Upgrade the installed Master System to a published tag with a verifiable snapshot, rollback and recovery.
- **validate** — Validate schemas, agents, domains and an optional project.
- **verify** — Evaluate verification readiness and missing evidence.
