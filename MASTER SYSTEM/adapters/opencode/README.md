# OpenCode Adapter (output)

This directory is the versioned distribution snapshot for assets generated by the OpenCode
adapter (`se adapter opencode`, ADR-0015 / ADR-0017 / ADR-0020). The adapter **is implemented**
since v0.6.0; it replaces the previous "planned" status.

## Adapter

- Module: `SCRIPTS/se_core/opencode/` (generator, mappings, validators).
- CLI: `se adapter opencode [--output <dir>] [--dry-run]`.
- Docs: [`DOCS/reference/opencode-adapter.md`](../../../DOCS/reference/opencode-adapter.md).
- Output manifest is governed by `SCHEMAS/adapter-manifest.schema.json` (input contracts ->
  artifacts + generated files + validation metadata, content-hash for drift detection).

## Generation

Contracts (`AGENTS/*/agent.json`, `COMMANDS/commands.json`, `SKILLS/*/SKILL.md`) are the single
source of truth. Generated artifacts (agents, commands, skills, `adapter-manifest.json`,
`AGENTS.md`) are emitted to the output directory — by default `.opencode/` at the repository root; projects
use `--output <proyecto>/.opencode`. A snapshot may be pinned here for distribution.

Do not edit generated files by hand; regenerate instead (`se adapter opencode`). The adapter
never writes into `PROJECTS/`.
